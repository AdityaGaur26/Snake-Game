# Snake Game

A simple Snake Game built using HTML, CSS, and JavaScript.

The player controls the snake using keyboard arrow keys. The snake grows after eating food, and the game ends if the snake collides with the wall or itself.

---

##  Features

- Snake movement
- Food generation
- Score tracking
- Game over detection
- Snake growth
- Keyboard controls
- Restart gameplay

---

##  Technologies Used

- HTML
- CSS
- JavaScript

---

##  Concepts Practiced

- DOM Manipulation
- Event Listeners
- Arrays
- setInterval()
- Collision Detection
- Game Logic
- Coordinate System

---

## 🎮 Controls

- ⬆️ Arrow Up
- ⬇️ Arrow Down
- ⬅️ Arrow Left
- ➡️ Arrow Right
